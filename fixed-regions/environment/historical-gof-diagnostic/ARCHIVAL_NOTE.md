# Nota sull'archivio del runtime diagnostico GoF

Sono inclusi soltanto patch, manifest e documentazione originali. Il wrapper `combine` e le librerie citati nel README storico **non sono distribuiti qui**. La patch aggiunge diagnostica al metodo GoodnessOfFit della campagna condivisa storica; non è applicata al runtime standard della procedura corrente. Il codice di costruzione originale è in `archive/scripts/shared_sr_cr_scan/build_gof_diagnostic_runtime.py`, dipende dalla vecchia installazione e non costituisce un installer portabile.
